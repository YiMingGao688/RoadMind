# 字体来源与许可

本应用使用了 **MiSans 字体**（小米）与 **Inter**（Rasmus Andersson）。字体作为 RoadMind 应用的一部分嵌入使用，不作为独立字体产品分发。

## MiSans

- 官方网站：<https://hyperos.mi.com/font/zh/>
- 嵌入使用说明：<https://hyperos.mi.com/font/zh/faq/>
- 官方下载包：<https://hyperos.mi.com/font-download/MiSans.zip>
- 原始文件：`MiSans/woff2/MiSans-Regular.woff2`、`MiSans/woff2/MiSans-Semibold.woff2`。
- 许可：同目录 `MiSans-License.pdf`，来自官方许可协议。
- 仅提取官方提供的完整 WOFF2 文件，未修改字形、名称或对字体进行子集化。归档 CRC32 与文件长度均已核验。
- 界面“关于 RoadMind 演示空间”中保留字体致谢。

两个完整中文字重合计约 9.9 MB；通过 `font-display: swap` 和浏览器静态资源缓存保障内容可先显示，不引入字体服务请求。后续如需进一步分包或子集化，应先确认对应授权范围。

## Inter

- 官方网站：<https://rsms.me/inter/>
- 原始文件：<https://rsms.me/inter/font-files/InterVariable.woff2>
- 许可：同目录 `Inter-OFL.txt`，SIL Open Font License 1.1。
- 字体文件保持原样，通过 CSS Unicode 范围将英文和数字交给 Inter 渲染。

来源核对日期：2026-10-26。
